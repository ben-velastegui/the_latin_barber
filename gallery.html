Instagram Feed Setup

To display your live Instagram feed:

  1. Option 1 - Elfsight (Easiest): Go to elfsight.com/instagram-feed, create a free widget, and replace the widget ID in the code above.
  2. Option 2 - Curator.io: Sign up at curator.io, create an Instagram feed, and uncomment the Curator.io code section.
  3. Option 3 - EmbedSocial: Visit embedsocial.com for another Instagram feed solution.
  4. Option 4 - Snapwidget: Use snapwidget.com to create a customizable Instagram widget.

Quick Start: Elfsight offers a free plan with 200 views/month. Just sign up, connect your Instagram account, customize the layout, and copy the embed code.
